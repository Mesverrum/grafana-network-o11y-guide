# Contributing

This repo is a **guide**. Keep it that way.

## What belongs here

- Quickstart, River samples, dashboard JSON, Explore queries, troubleshooting
- Pointers to [snmp-sd](https://github.com/Mesverrum/snmp-sd), [grafana/alloy](https://github.com/grafana/alloy), and the [network-snmp fork](https://github.com/Mesverrum/alloy)

## What does not

- Collector source (Alloy, snmp-sd)
- A ContainerLab Clos, colocated Terraform, or dual-write ktranslate lab — that is [network-o11y-demo](https://github.com/Mesverrum/network-o11y-demo)
- Real `.env`, `alloy/auths.yml`, or communities in Fleet samples

## README is a thin index

Depth lives in `docs/` and `troubleshooting/`. When you add a capability, add a one-line pointer under **Going further**.
